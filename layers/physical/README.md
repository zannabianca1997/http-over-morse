# Physical layer

Implementation of the [physical
layer](https://en.wikipedia.org/wiki/Physical_layer) of the OSI model:
conversion from the morse code to bytes.

## Prosigns

The morse code uses
[prosigns](https://en.wikipedia.org/wiki/Prosigns_for_Morse_code) to separate
and manage messages. I thought it would be cool to use them too, so they are
used as out of band info to communicate.
