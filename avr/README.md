# AVR firmware

AVR specific software. Crates in this workspace can only be compiled for AVR,
and need an AVR specific toolchain.

## Build prerequisite 

Install prerequisites as described in the [`avr-hal` quickstart] (`avr-gcc`,
`avr-libc`, `avrdude`, [`ravedude`]).

[`avr-hal` quickstart]: https://github.com/Rahix/avr-hal#quickstart
[`ravedude`]: https://crates.io/crates/ravedude
